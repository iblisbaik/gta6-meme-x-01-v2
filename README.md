A GTA 6 launch-week meme, v2: a package-tracking screen for a GTA VI order placed on 17 Sep 2013 — out for delivery at last, 4,811 days later, with the make.fun ghost as the courier who earned real money while the package was in transit. The post itself is the entry: it goes up on X from a public account, the house reads it from X, and an AI judge compares the posts two at a time. The top 50 share $500 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
